BLOQUE 1: Configuración de Hyper-V y Rocky Linux

- Hyper-V: es un hipervisor de tipo 1 o bare metal, es decir, se ejecuta directamente sobre el hardware físico del ordenador y actúa como si fuese el sistema operativo. Al activarlo y reiniciar el ordenador es Hyper-V el que se inicia primero sobre el hardware, y luego Windows 11 sobre él, dando la ilusión de que seguimos usando Windows 11 nativo cuando en realidad es solamente una VM privilegiada

Para activar Hyper-V y llevar todas las máquinas virtuales a mi disco E: (que es el que más espacio disponible tiene) he seguido estos pasos:

  1. Ejecutar estos comandos en PowerShell como admin:
  
      Qué tipo de disco es E: (SSD/HDD, interno/USB)
        Get-Partition -DriveLetter E | Get-Disk | Select-Object FriendlyName, BusType
        Get-PhysicalDisk | Select-Object FriendlyName, MediaType, BusType
      
      Activar Hyper-V
        Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All

  2. Depués de reiniciar ejecutar:

      Get-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V | Select-Object State

      New-Item -ItemType Directory -Path E:\HyperV\VHD, E:\HyperV\VMs, E:\HyperV\ISO -Force
      Set-VMHost -VirtualHardDiskPath 'E:\HyperV\VHD' -VirtualMachinePath 'E:\HyperV\VMs'
      Get-VMHost | Select-Object VirtualHardDiskPath, VirtualMachinePath
  
  3. Descargar la ISO de Rocky Linux 9 para las máquinas, versión minimal, desde https://rockylinux.org/download

BLOQUE 2: Red interna con NAT

  Vamos a crear un switch virtual (que actúa como un switch físico) al que vamos a conectar las 4 máquinas virtuales y mi propia máquina Windows que servirá como router con NAT hacia mi red real. De esta manera la IP de las máquinas será siempre fija y no dependen de dónde esté. Tampoco habrá DHCP, cada máquina tendrá su IP configurada a mano.

  Tras ejecutar el script 01-red-ps1, que crea el switch virtual con New-VMSwitch; configura la IP de Windows en dicho switch con New-NetIPAddress; y configura una NAT con New-NetNat

  Para comprobar que se ha creado correctamente podemos ejecutar Get-NetNat y observar la salida. En este caso mi ejecución ha sido exitosa:
